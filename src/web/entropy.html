Entropy generator

Extra randomness for your hardware wallet

Mixes your browser's cryptographic RNG with your own mouse, touch and keyboard input into a BIP-39 recovery phrase (or raw hex) you can use as an independent, extra entropy source alongside a hardware wallet's own RNG — never trust one RNG alone.

Read this before you use it.
  • This is supplementary entropy, not a replacement for anything. Use it as an independent, extra entropy source alongside a hardware wallet's own RNG — never trust a single source, including this page, for a wallet holding real value.
  • This tool is open source and served live from a public website. For anything holding real value: use your browser's "Save Page As → Webpage, HTML only" to get a self-contained file that runs from disk with no server, no connection required (this page has no external scripts) — or better, read the source and build it yourself from the repo and run it with cargo run -- --serve --db crawl.db, so nothing you use was ever fetched live.
  • Never type a recovery phrase into any website. This page only ever shows you one it generated itself, for you to write down by hand.
  • Ideally disconnect from the network before generating, and definitely before entering anything into a hardware wallet.
  • Nothing here is sent anywhere or saved to disk — check your browser's Network tab if you'd like to confirm that yourself.

1. Add your own randomness

Move your mouse or finger over the pad below, click around, mash a few keys. This is hashed on top of your browser's own CSPRNG (already cryptographically secure on its own) — think of it as a second, independent ingredient, not the main source of security. The counter below is a deliberately conservative, illustrative estimate of your contribution specifically, and keeps rising for as long as you keep interacting — it's separate from the final key space, which is always exactly fixed at 128 or 256 bits by your choice in step 2 (that part genuinely can't grow, however long you interact — a 256-bit value can't hold more than 256 bits of entropy), but every extra independent round you feed in is still a real, additional hedge on top of it.

~0 bits of interaction entropy (conservative estimate)

2. Generate

Pick a length and generate. Either one is guaranteed by your browser's CSPRNG alone, independent of the interaction counter above — that counter is a bonus hedge, not a requirement for reaching full security. The output is blurred until you click to reveal it — so it isn't casually visible on a shared screen or in a screenshot/recording.
